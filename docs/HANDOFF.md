# AI 协作交接

## 当前目标

完成可复用、低耦合的核心资产备份平台：生成、传输、校验、保留策略、告警相互独立；标准结果驱动控制台和每日报告；通过隔离恢复证明可恢复性。

## 展示页下一阶段

以 prototype 下的 HTML 为视觉和交互基准，复用现有 apps/board 的认证、PostgreSQL 和人工验收。

1. 明确每项资产计划、截止时间、预期副本及新鲜度。
2. 持久化每日快照和每次运行结果。
3. 接入每日统计、异常、历史和脱敏日志接口。
4. 替换原型内嵌示例数据，保留搜索、日期、详情标签交互。
5. 验证管理员及只读用户、空数据、旧数据、部分成功和采集失败。

## 建议分工

| 任务 | 负责人角色 | 交付 |
| --- | --- | --- |
| UI-01 | Gemini / Antigravity | 原型前端、响应式、接口适配；不操作生产 |
| DATA-01 | OpenCode | 历史模型、查询接口、测试 |
| INTEGRATION-01 | 统一负责人 | 生产版本核对、口径、接入与部署 |
| DOC-01 | 文档协作者 | 部署及恢复手册、验收证据索引 |

任务开始时在独立分支登记负责范围。不要多人同时编辑同一模块。
