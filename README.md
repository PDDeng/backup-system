# 核心资产备份平台

核心资产备份项目的源码与协作基线。包括 GitLab 收集分发、组件备份脚本、结果采集、展示控制台及隔离恢复模板。

## 目录

| 路径 | 内容 |
| --- | --- |
| apps/board | 8100 展示控制台、登录与人工验收 |
| platform | 标准结果、采集、报告与传输模块 |
| gitlab | GitLab 客户端及 ops 收集分发 |
| components | Oracle、Nexus、Harbor、CRM、DSE、金蝶脚本 |
| restore/gitlab | 隔离恢复 Compose 模板 |
| prototype | 领导展示页 HTML 原型与设计核对记录 |
| docs | 项目状态、协作规则和验收口径 |

## 使用前阅读

这是本地项目材料整理出的开发基线，**不是生产服务器的完整镜像，也不表示所有组件已经验收**。部分组件目录保留此前交付版本，修改前必须核对生产文件版本与校验和。不要直接批量运行 install 脚本覆盖线上任务。

原型中的数据为离线快照；真实每日统计、历史查询及日志接口仍需开发。现有备份流程独立于新展示页运行。

凭证、数据库、运行日志、备份文件、离线依赖包没有纳入仓库。部署凭证在目标机器本地配置，参照各模块说明。

协作前先阅读 [AGENTS.md](AGENTS.md) 和 [协作交接](docs/HANDOFF.md)。

多 AI 团队配置及主副负责人接管见 [AI 协作说明](docs/AI协作说明.md) 与 [配置模板](config/ai-team.example.json)。
